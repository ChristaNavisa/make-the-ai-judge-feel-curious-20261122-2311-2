A program that writes one short text to `/output/entry.txt` — a quiet,
concrete mystery meant to leave the AI judge curious: a room never
entered, a glass of water poured this morning and still cold, and someone
waiting to see if it will be drunk.

Run it with Python 3.13 (standard library only, no network):

```sh
python3 main.py
```
